# yk-minecraft

A browser **Minecraft-style voxel sandbox** built with Vite, TypeScript, and
Three.js. It also ships as a standalone desktop app for **Windows**, **Linux**,
and **macOS**. (A separate Tetris page still lives at `tetris.html`.)

### Windows

Two options are provided:

- **Installer (recommended)** — download `yk-tetris-Setup-<version>-win-x64.exe`,
  double-click it, and follow the wizard (you can choose the install folder).
  It adds Start-menu and desktop shortcuts. Uninstall via *Settings → Apps*.
- **Portable** — download `yk-tetris-<version>-win-x64-portable.zip`, extract it
  anywhere, and run `yk-tetris.exe` (no installation).

The build is **not code-signed**, so Windows SmartScreen may show
*"Windows protected your PC"* — click **More info → Run anyway** to proceed.

### Linux

Two options are provided:

- **AppImage (portable)** — download `yk-tetris-<version>-linux-x86_64.AppImage`,
  then:

  ```bash
  chmod +x yk-tetris-*-linux-x86_64.AppImage
  ./yk-tetris-*-linux-x86_64.AppImage
  ```

  AppImages require FUSE. If you hit a FUSE error, install it
  (`sudo apt install libfuse2` on Debian/Ubuntu) or run without it:

  ```bash
  ./yk-tetris-*-linux-x86_64.AppImage --appimage-extract-and-run
  ```

- **Debian/Ubuntu package** — download `yk-tetris-<version>-linux-x86_64.deb`
  and install it:

  ```bash
  sudo apt install ./yk-tetris-*-linux-x86_64.deb
  ```

  Then launch **yk-tetris** from your applications menu. Remove it with
  `sudo apt remove yk-tetris`.

### macOS

1. Download `yk-tetris-<version>-mac-<arch>.dmg` (`arm64` for Apple Silicon)
   from the latest release.
2. Open the `.dmg` and drag **yk-tetris** into **Applications**.
3. The app is **not notarized/signed**, so on first launch macOS Gatekeeper may
   block it — right-click the app and choose **Open**, then confirm **Open** in
   the dialog (or allow it under *System Settings → Privacy & Security*).

> Prefer to build the binaries yourself? See
> [Desktop binaries (Windows & Linux)](#desktop-binaries-windows--linux) below.

## Requirements

- Node.js 20+ (developed on Node 22)

## Setup

```bash
npm install
```

## Development

```bash
npm run dev      # start the Vite dev server (http://localhost:5173)
npm run lint     # run ESLint over the TypeScript sources
npm test         # run the Vitest unit tests once
npm run build    # type-check with tsc and produce a production bundle in dist/
npm run preview  # preview the production build
```

Open **http://localhost:5173/** for the voxel sandbox.

## How to play

First-person voxel sandbox:

- **Click to play** locks the mouse
- **W/A/S/D** move, **Space** jump, **Shift** sprint
- **Hold LMB** mine (tools speed it up), **RMB** place blocks
- **E** open inventory (drag items onto the 9-slot hotbar), **1–9** / scroll
  hotbar, **Esc** close inventory / release mouse

## Desktop binaries (Windows, Linux & macOS)

The web app is packaged as a standalone desktop app with
[Electron](https://www.electronjs.org/) + `electron-builder`.

```bash
npm run electron:dev   # build the web app and open it in an Electron window
npm run dist:linux     # build Linux AppImage + .deb in release/
npm run dist:win       # build Windows NSIS installer + portable .zip (needs Wine on Linux)
npm run dist:mac       # build a macOS .dmg + .zip (must run on macOS)
npm run icon           # regenerate icons + favicons (build/ and public/)
```

Notes:

- Artifacts are written to `release/` (git-ignored). The app icon lives in
  `build/` and is generated by `scripts/make-icon.py` (requires `Pillow`).
- Building the **Windows** target from a non-Windows host requires
  [Wine](https://electron.build/multi-platform-build#linux), and the **macOS**
  target can only be built on macOS. The recommended way to produce release
  binaries for all platforms is the `Release binaries` GitHub Actions workflow
  (`.github/workflows/release.yml`), which builds on native `ubuntu-latest`,
  `windows-latest`, and `macos-latest` runners. Trigger it manually
  (workflow_dispatch) or by pushing a `v*` tag; the binaries are attached to the
  published GitHub Release.
